### 1. Постановка задачи

> Напишите программу на Java, которая выполняет следующие действия с двумерным массивом символов (строчные и заглавные буквы латинского алфавита):
> 1. Считывает с консоли размер массива N, затем элементы массива размером N × N.
> 2. Сортирует столбцы массива в порядке возрастания количества гласных букв в каждом столбце. При этом внутри столбца символы остаются на своих местах. Если показатели равны, сортирует столбцы по сумме ASCII-кодов символов.
> 3. Находит и выводит символ, который чаще всего встречается в массиве (без учёта регистра). Если таких символов несколько, выводит все.
> 4. Выводит элементы массива в виде спирали, начиная с центрального элемента и двигаясь против часовой стрелки. Реализовать алгоритм без использования дополнительных массивов.
> 5. Шифрует массив, изменяя регистр букв на противоположный, выводит зашифрованный массив.

Данную задачу можно разделить на 5 подзадач:
1. **Ввод:** Считать размер матрицы и её элементы.
2. **Сортировка:** Для каждого столбца посчитать гласные и сумму ASCII. Отсортировать индексы столбцов по заданным критериям и собрать новую матрицу.
3. **Поиск частого символа:** Пройтись по матрице, посчитать частоту каждой буквы (независимо от регистра), найти максимум и вывести все буквы с этим максимумом.
4. **Спираль:** Начать с центра, двигаться вправо, вверх, влево, вниз, увеличивая длину шага каждые 2 направления.
5. **Шифрование:** Пройтись по матрице и заменить каждую букву на противоположную по регистру (a->A, B->b).

### 2. Входные и выходные данные

#### Данные на вход

| Переменная | Тип               | Описание                   |
|------------|-------------------|----------------------------|
| N          | Целое число (int) | Размерность матрицы (N × N)|
| a[i][j]    | Символ (char)     | Латинские буквы (a-z, A-Z) |

#### Данные на выход

| Данные                  | Тип     | Описание                            |
|-------------------------|---------|-------------------------------------|
| Отсортированная матрица | Символы | Матрица с переставленными столбцами |
| Частые символы          | Символы | Буквы с максимальной частотой       |
| Спираль                 | Символы | Элементы массива в порядке спирали  |
| Зашифрованная матрица   | Символы | Матрица со сменой регистра          |

### 3. Выбор структуры данных

| Что храним  | Название переменной | Тип (в Java) |
|-------------|---------------------|--------------|
| Матрица     | `a`                 | `char[][]`   |
| Гласные     | `vowels`            | `int[]`      |
| Сумма ASCII | `sum`               | `int[]`      |
| Индексы     | `order`             | `int[]`      |
| Частоты     | `count`             | `int[]`      |

Для хранения самой матрицы используется двумерный массив символов `char[][]`. Для подсчета метрик столбцов используются одномерные массивы `int[]`. Для поиска частых символов используется массив на 26 элементов (по количеству букв в алфавите). Дополнительные массивы для спирали не используются согласно условию.

### 4. Алгоритм

#### Алгоритм выполнения программы:

1. **Ввод данных:** Считываем `N`, затем `N*N` символов.
2. **Сортировка:**
    - Считаем `vowels[j]` и `sum[j]` для каждого столбца `j`.
    - Инициализируем массив `order` числами от 0 до N-1.
    - Сортируем `order` пузырьком, сравнивая столбцы по (1) гласным, (2) сумме ASCII.
    - Переставляем столбцы в матрице согласно `order`.
3. **Частый символ:**
    - Заполняем массив `count[26]`, увеличивая счетчик для буквы (приводим заглавные к строчным через ASCII).
    - Находим `max` в `count`.
    - Выводим все буквы, у которых `count[k] == max`.
4. **Спираль:**
    - Определяем центральную клетку (для четного N — левую-нижнюю из четырех).
    - Печатаем центр. Затем в цикле `while` движемся вправо, вверх, влево, вниз. Длина шага (`stepLen`) увеличивается каждые 2 направления.
5. **Шифрование:**
    - Проходим по матрице. Если символ `a-z`, меняем на `A-Z` (вычитаем 32 из ASCII). Если `A-Z`, меняем на `a-z` (прибавляем 32).

### 5. Программа

```java
import java.util.Scanner;
import java.io.PrintStream;

public class Main {

    // ======================
    // Глобальные переменные.
    // ======================

    static int n;
    static char [][]a;

    static PrintStream out = System.out;

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        // =================================================
        // Пункт 1: Считываем размер матрицы и заполняем ее.
        // =================================================

        n = in.nextInt();
        a= new char[n][n];

        for(int i = 0; i < n; i++){
            for(int j = 0; j < n; j++){
                a[i][j] = in.next().charAt(0);
            }
        }

        // Вызов подпрограмм для пунктов.
        sortColumns();
        printMostFrequentChar();
        printSpiral();
        encryptAndPrint();

    }

    // ===========================================================================
    // Пункт 2 : Сортировка столбцов по возрастанию гласных, затем по сумме ASCII.
    // ===========================================================================

    static void sortColumns(){

        int[] vowels = new int[n]; // Массив для хранения количества гласных в каждом столбце.
        int[] sum = new int[n];    // Массив для хранения суммы ASCII-кодов в каждом столбце.

        // Шаг 1: Считаем гласные и суммы кодов для каждого столбца.

        for(int i = 0; i < n; i++){
            for(int j = 0; j < n; j++){

                char ch = a[i][j];
                if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u'
                        || ch == 'A' || ch == 'E' || ch == 'I' || ch == 'O' || ch == 'U'){
                    vowels[j]++;
                }
                sum[j] += (int) ch;
            }
        }

        // Шаг 2: Создаем массив индексов. Сортируем номера столбцов.

        int[] order = new int[n];
        for(int j = 0; j < n; j++){
            order[j] = j;
        }

        // Шаг 3: Пузырьковая сортировка массива индексов.

        for(int i = 0; i < n - 1; i++){
            for(int j = 0; j < n - 1 - i; j++){
                int x = order[j];
                int y = order[j + 1];
                boolean needSwap = false;

                // Сравнение по:

                    // 1. Количеству гласных.
                if(vowels[x] > vowels[y]){
                    needSwap = true;

                    // 2. Если гласных поровну - по сумме ASCII-кодов.
                }else if(vowels[x] == vowels[y]){
                    if(sum[x] > sum[y]){
                        needSwap = true;

                        // 3. Если и коды равны - по изначальному индексу.
                    }else if(sum[x] == sum[y] && x > y){
                        needSwap = true;
                    }
                }

                // Меняем местами номера столбцов.

                if(needSwap){
                    order[j] = y;
                    order[j + 1] = x;
                }
            }
        }

        // Шаг 4: Собираем новый массив по отсортированным номерам столбцов.

        char [][] sorted = new char[n][n];
        for(int i = 0; i < n; i++){
            for(int j = 0; j < n; j++){
                sorted[i][j] = a[i][order[j]];
            }
        }

        // Запоминаем обновленный массив.

        a = sorted;

        out.println("Пункт 2 (сортировка)");

        for(int i = 0; i < n; i++){
            for(int j = 0; j < n; j++){
                out.print(a[i][j] + " ");
            }
            out.println();
        }
    }

    // ==============================
    // Пункт 3 : Самый частый символ.
    // ==============================

    static void printMostFrequentChar(){

        // Массив индексов букв без учета регистра.

        int[] count = new int[26];

        for(int i = 0; i < n; i++){
            for(int j = 0; j < n; j++){
                char ch = a[i][j];

                if(ch >= 'a' && ch <= 'z'){
                    count[ch - 'a']++;      // Для строчных.
                }else if(ch >= 'A' && ch <= 'Z'){
                    count[ch - 'A']++;      // Для заглавных.
                }
            }
        }

        // Находим максимальную частоту повторений.

        int max = 0;
        for(int i = 0; i < 26; i++){
            if(count[i] > max){
                max = count[i];
            }
        }

        out.println("Пункт 3 (символ, который чаще всего встречается)");
        for(int i = 0; i < 26; i++){
            if(count[i] == max){
                out.print((char)('a' + i) + " "); // Преобразует индекс обратно в символ.
            }
        }
        out.println();
    }
    // ============================================
    // Пункт 4 : Вывод элементов массива по спирали
    // ============================================

    static void printSpiral(){
        out.println("Пункт 4 (элементы массива в виде спирали)");

        int r,c; // Координаты клетки.

        if(n % 2 == 1){
            r = n/2;
            c = n/2;
        }else{
            r = n/2;
            c = n/2 -1;
        }

        int total = n * n;
        int done = 0; // Сколько элементов напечатаны.

        // Печатаем центральный элемент

        out.print(a[r][c] + " ");
        done++;

        int step = 1; // Длина текущего шага

        while(done < total){
            // Вправо
            for(int i = 0; i < step && done < total; i++){
                c++;
                out.print(a[r][c] + " ");
                done++;
            }
            // Вверх
            for(int i = 0; i < step && done < total; i++){
                r--;
                out.print(a[r][c] + " ");
                done++;
            }
            step++;

            // Влево
            for(int i = 0; i < step && done < total; i++){
                c--;
                out.print(a[r][c] + " ");
                done++;
            }
            // Вниз
            for(int i = 0; i < step && done < total; i++){
                r++;
                out.print(a[r][c] + " ");
                done++;
            }
            step++;
        }
        out.println();
    }

    // ===================
    // Пункт 5: Шифрование
    // ===================

    static void encryptAndPrint(){
        out.println("Пункт 5 (зашифрованный массив)");

        for(int i = 0; i < n; i++){
            for(int j = 0; j < n; j++){
                char ch = a[i][j];

                if(ch >= 'a' && ch <= 'z'){
                    ch = (char)(ch - 32); // Из строчной в заглавную
                }else if(ch >= 'A' && ch <= 'Z'){
                    ch = (char)(ch + 32); // Из заглавной в строчную
                }

                a[i][j] = ch;
                out.print(a[i][j] + " ");
            }
            out.println();
        }
    }
}
```
